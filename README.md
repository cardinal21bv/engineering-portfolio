# Cameron McConnell — Engineering Portfolio

A responsive, one-page engineering portfolio focused on controls, industrial automation, electromechanical systems, HVAC controls, and building automation.

**Live portfolio:** [cardinal21bv.github.io/engineering-portfolio](https://cardinal21bv.github.io/engineering-portfolio/)

## Featured work

### Industrial Valve Automation System

An end-to-end quarter-turn valve system integrating a Siemens S7-1200 PLC, TIA Portal, custom HMI/SCADA software, Arduino motion control, encoder feedback, limit switches, current sensing, electrical design, and a SolidWorks-designed drivetrain.

- PLC sequencing, interlocks, command arbitration, and fault handling
- Custom local and remote HMI/SCADA controls
- Closed-loop sensing and current-based fault detection
- Mechanical, electrical, embedded, and software system integration
- Four-page case study and system demonstration video

### Climate-Responsive Office BAS Design

A Seattle office design connecting envelope decisions and Manual J HVAC loads with equipment selection, occupancy and CO2 sensing, thermostat controls, alarms, and energy-performance analysis.

## Technical toolkit

- **Controls:** Siemens S7-1200 PLC, TIA Portal, PLC programming, HMI/SCADA
- **Embedded and electrical:** Arduino, instrumentation, sensors, electrical schematics
- **Building systems:** HVAC, BAS, energy monitoring, control sequences
- **Engineering software:** SolidWorks, MATLAB/Simulink, Python
- **Practice:** system integration, troubleshooting, testing, commissioning, technical documentation

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
